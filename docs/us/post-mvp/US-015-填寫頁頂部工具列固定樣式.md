### US-015：填寫頁頂部工具列固定樣式

**作為** 使用者
**我想要** `/fill/[id]` 頂部工具列維持截圖中的排版，並在捲動時固定於頂端、不透明蓋住下方內容
**以便** 隨時操作返回、新增區塊與匯出，而不被 PDF 內容蓋住

---

**輸入格式**：已成功載入 PDF 的填寫頁（`src/app/fill/[id]/page.tsx` 頂部工具列）

**輸出格式**：同一工具列改以 Tailwind class 表達 sticky 定位與背景，不使用 inline `style`

**驗收條件**：
- [ ] 工具列保留 `flex items-center gap-2 border-b px-4 py-2`
- [ ] 工具列為 `position: sticky`、`top: 0`、`z-index: 1`
- [ ] 背景為主題 background（淺色模式等同白色），不以 inline style 寫死 `white`
- [ ] 僅調整填寫頁此工具列，不改素材管理頁 header

**測試策略**：不寫自動化測試
> 純 UI 排版／樣式；專案無 Jest／Vitest／Playwright script，以瀏覽器對照截圖驗證。

**依賴關係**：US-005a（填寫頁框架）

**優先級**：P2
**相關功能**：PDF 填寫頁工具列
