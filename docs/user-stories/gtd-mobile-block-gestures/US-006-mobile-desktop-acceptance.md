### US-006：常見手機尺寸與桌機回歸驗收

**作為** 使用者
**我想要** 在常見手機寬度與桌機上都確認三種區塊可操作
**以便** 合併前鎖定 Notion 完成標準

**輸入格式**：
- 已完成的 US-004、US-005
- 填寫頁一張測試 PDF，各放文字、圖片、簽名各一塊
- 視窗寬度：360、390、430（常見手機）；≥1024（桌機）

**輸出格式**：
- 本檔「驗收條件」勾選結果（實作 agent 在瀏覽器或 DevTools device mode 跑完後勾）
- 若有缺口：在對應 US 補修，不另開範圍外功能

**驗收條件**：
- [ ] 360／390／430 寬度下，文字、圖片、簽名皆可移動
- [ ] 同上寬度，三種區塊皆可縮放，且過程即時
- [ ] 操作結束後重新選取區塊，位置與尺寸仍正確
- [ ] 拖曳／縮放時頁面不因該手勢誤捲
- [ ] 桌機（滑鼠）拖曳與縮放與改前一致
- [ ] 三種區塊經移動／縮放後匯出 PDF，位置與尺寸與畫面上一致

**測試策略**：Test-After
> 理由：跨裝置手勢與匯出對位需真實／模擬視窗驗收，不適合預先寫死自動化。

**依賴關係**：US-004、US-005

**優先級**：P0
**相關功能**：Notion 完成標準與細項檢核（手機尺寸、保留、桌機）
